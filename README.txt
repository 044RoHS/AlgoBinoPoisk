 Задание 1. Оценка алгоритмической сложности программы

 Описание функции
Функция принимает два параметра: массив и его размер. Внутри неё объявлена локальная переменная. Цикл вычисляет сумму разностей между соседними элементами массива.

 Временная сложность: O(n)
- Обоснование:  
  Каждый элемент массива рассматривается ровно один раз.  
  Цикл выполняет `(size - 1)` итераций, где `size` — размер массива.  
 

 Пространственная сложность: O(1)
- Обоснование: 
  Используются только константные переменные:  
  - `ans` (для накопления суммы).  
  - `i` (счётчик цикла).  
  Дополнительная память не зависит от размера входных данных.

 Итог
Алгоритмическая сложность не является критичной:  
- Линейное время O(n) и константная память O(1) — оптимальные показатели для подобных задач.  
- Использование одного цикла гарантирует эффективность на больших данных.
